# Prince Jewellers – Business Analytics

A jewellery business analytics project built using Python, Pandas, Excel and Power BI to analyse business performance and generate meaningful insights.

## Tools Used
- Python & Pandas
- Microsoft Excel
- Power BI
- Matplotlib

## Project Analysis
- Monthly Sales Analysis
- Category-wise Sales Performance
- Customer Payment & Outstanding Analysis
- Purchase & Artisan Cost Analysis
- Monthly Shop Expenses
